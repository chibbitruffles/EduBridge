# EduBridge – User Flow

## Overview

This document describes the navigation and basic interactions within the EduBridge mobile application.

## Main User Flow

1. **Splash Screen** – Displays the EduBridge application identity.
2. **Authentication** – Users can log in or create an account.
3. **Dashboard** – Provides access to learning categories, recent activities, and application features.
4. **Learning Materials** – Allows students to browse and access educational resources.
5. **PDF Viewer** – Allows students to read available learning documents.
6. **Quizzes** – Provides interactive assessments for reviewing lessons.
7. **Quiz Results** – Displays scores, results, and answer reviews.
8. **Bookmarks** – Provides access to saved learning materials.
9. **Progress Tracking** – Displays learning progress and quiz history.
10. **Profile and Settings** – Allows users to manage their account information and preferences.

## Navigation

The application provides navigation between the dashboard, learning materials, quizzes, bookmarks, progress, and profile sections.

*Note: This user flow describes the planned application experience and should be updated as the design and implementation progress.*
